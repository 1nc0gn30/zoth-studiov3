## 🛡️ What is Zoth Studio?

**Zoth Studio v12.0.0** is an uncompromising, 100% local-first **Multi-Agent AI Operating System** and sovereign **Web Foundry** — a cyberpunk-themed command center that puts you in full control of your AI stack. No cloud lock-in. No telemetry. No subscriptions. Every bit runs on `127.0.0.1`.

It ships as a unified workstation suite: a **Cyberpunk Tactical HUD** cockpit, a **21-Agent Swarm Pantheon**, a **Global Fuzzy Command Palette**, a **Netrunner 3D Memory Graph**, a **Multi-Agent REPL Debate Simulator**, a **PTY terminal**, a **298+ Tool Nexus**, an **E2EE Vault Daemon**, and a full **Android companion app** — all orchestrated over loopback. Build, run, create, and collaborate without ever touching the internet.

- **Primary Repo**: [`core-app/`](core-app/README.md) → [`github.com/NullAITech/zoth-studio`](https://github.com/NullAITech/zoth-studio)
- **Architecture**: 100% Loopback `127.0.0.1` · Zero Cloud Telemetry · Zero Remote Lock-in
- **Binaries**: [releases-and-binaries/](releases-and-binaries/README.md) · [GitHub Releases](https://github.com/NullAITech/zoth-studio/releases)

## ⚡ Quick Start

### 1. Launch the Web Hub & Cyberpunk HUD (`:8088`)

```bash
cd core-app/public
python3 -m http.server 8088 --bind 127.0.0.1
```

| URL | What You Get |
|:---|:---|
| [http://127.0.0.1:8088/](http://127.0.0.1:8088/) | 🌐 Flagship Hub & Showcase |
| [http://127.0.0.1:8088/studio/cyberpunk-hud.html](http://127.0.0.1:8088/studio/cyberpunk-hud.html) | 🎮 Cyberpunk Tactical HUD Cockpit |
| [http://127.0.0.1:8088/studio/tool-nexus.html](http://127.0.0.1:8088/studio/tool-nexus.html) | 🛠️ Tool Nexus (298+ Tools) |
| [http://127.0.0.1:8088/docs/readmes.html](http://127.0.0.1:8088/docs/readmes.html) | 📚 Interactive README Library |
| [http://127.0.0.1:8088/docs/](http://127.0.0.1:8088/docs/) | 📖 Documentation Portal |

### 2. Launch Local Daemons

```bash
# Operator Deck & PTY Terminal (:8484)
python3 core-app/tools/orchestrator.py

# Lucy Cognitive Memory Daemon (:8788)
python3 memory-daemon/memory-ui-server.py

# Keymaster Argon2id Vault Daemon (:8787)
./releases-and-binaries/linux/zoth-vault-daemon --port 8787
```

### 3. Use the Global CLI (`zoth`)

```bash
zoth status       # Real-time loopback stack health & latency
zoth tui          # Launch full-screen Curses TUI
zoth doctor       # System dependency & security health check
zoth mem list     # Browse synaptic memory digests
zoth list         # Search 298+ registered tools
```

### 4. Open the Global Command Palette

Press **`Ctrl+K`** (or **`⌘K`** on macOS) anywhere in the HUD to open the **Global Fuzzy Command Palette** — search across all workstations, agents, tools, and commands instantly.
