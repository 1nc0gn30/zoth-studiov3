# Risk Summary — Layout C (/studio/ subpath)

Deploying the Zoth public hub as `nullai.tech/studio/` is the lowest-cost Layout C option because it avoids extra DNS and an apex overwrite, but it carries the highest path-collision risk of the three layouts: any pre-existing `public_html/studio/` tree, future apex `/studio` routes, or stale `zoth.nealfrazier.tech/studio/` links can interleave with or shadow the Zoth subtree. The mitigations — pre-flight snapshot, explicit `mkdir -p public_html/studio`, rsync with `--delete` plus a tight exclude list, canonical URL updates, and a 301 redirect map — are deterministic and cheap, and they should be executed before and after every deploy to keep the subtree isolated, unambiguous, and safe for both search engines and returning visitors.
