## ⚡ Overview & Key Capabilities

**Zoth** is the flagship application powering the entire **Zoth Studio** ecosystem.

### Core Architecture:
- 🤖 **Agentic AI Swarm:** Multi-agent arbitration with Shannon entropy and Jaccard token overlap between Antigravity, Grok, Hermes, and local Ollama (`zoth-micro`).
- 🧊 **Nexus 3D Omniverse:** High-fidelity Three.js 3D viewport with GLTF/OBJ asset inspector and procedural shaders.
- 📟 **ESP32-S3 Physical Companion:** Lafvin board hardware integration with ST7789 IPS display, ES8311 I2S audio, and bidirectional JSON serial protocol.
- 🔐 **Rust Argon2id BYOK Vault:** Zero-leak memory security and XChaCha20-Poly1305 authenticated encryption.
- 🎬 **OmniPost 2.0 Video Engine:** 60 FPS HTML5 Canvas video and thumbnail generator with Web Speech narration.
- 🛡️ **OWASP Hardened:** Pre-configured Content Security Policy (CSP), DOMPurify sanitization, and strict loopback binding (`127.0.0.1`).
