A futuristic, local-first 3D Stoicism portal engineered with Three.js particle canvas, Marcus Aurelius Meditations database, ambient Web Audio synthesizer, and responsive cyberpunk dark UI.

## ⚡ Core Features

### 1. 🌌 Holographic 3D Particle Canvas (`Three.js`)
- **10,000 Interactive Particles**: Float32 GPU buffer with smooth physics, additive blending, and distance attenuation.

  1. `[1] Citadel Core`: Nested Dodecahedron & Hexagonal Bastion shield walls.

### 2. 📜 Curated Marcus Aurelius *Meditations* Neural Engine
- **Categorized by the 6 Stoic Pillars**:
  - *The Inner Citadel* (`citadel`)
  - *Amor Fati* (`amor-fati`)
  - *Memento Mori* (`memento-mori`)
  - *Dichotomy of Control* (`dichotomy`)
  - *Cosmic Logos* (`logos`)
  - *Discipline & Action* (`discipline`)

- **Text-to-Speech Audio**: Web Speech API speech synthesis with deep stoic cadence.
- **Holographic Card Exporter**: Generates and downloads high-res 1200x675 PNG cyber cards with custom typography, borders, and citations.

- **📖 Meditations Neural Codex**: Realtime searchable and filterable database archive.
