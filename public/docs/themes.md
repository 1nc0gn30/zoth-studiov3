# Themes

Sixty palettes. Storage: `localStorage.zoth-theme`. DOM: `html[data-theme="…"]`. Cycle: **Shift+T**.

Picker lives in the shared navbar and in the HUD header.

## Groups

**Studio originals** — Dark Void, Solar Light, Matrix CRT, Hermetic Gold, Dusk Rose, Abyssal Ocean, Forge Ember, Newsprint, Navy Signal, Amethyst Void, Moss Sanctum, Copper Patina, Alpine Snow, Vellum Champagne, Crimson Ledger, Jade Circuit, Indigo Chapel, Coral Dusk, Ivory Gallery, India Ink, Twilight Orchid, Iron Rust, Pearl Lilac, Graphite Lead.

**Frontier** — Google, Microsoft, Apple, OpenAI, AWS, Anthropic, xAI, Meta, NVIDIA, Hugging Face, Mistral, Vercel, DeepSeek, Perplexity, Cursor, Groq, Cohere, Stripe, Cloudflare.

**Editors / dev** — Dracula, Nord, Synthwave, Solana, Monokai, Tokyo Night, Catppuccin, Gruvbox, Solarized, One Dark, GitHub Dark, Rosé Pine, Everforest, Ayu, Night Owl, Oxocarbon, Flexoki.

## Light themes (honest paper)

`light`, `paper`, `snow`, `champagne`, `ivory`, `pearl` set `color-scheme: light` and dark ink. They are not inverted dark mode.

## Files

- `public/assets/zoth-theme.js` — registry
- `public/assets/zoth-theme-life.css` — type, radius, header per ID
- `public/assets/zoth-theme-pack-*.css` — palettes
- `public/assets/zoth-theme-fx.css` / `.js` — atmosphere
