📦 6. Linux Universal Binary & Compilation Pipeline

Zoth Studio compiles into 3 standalone distribution formats for any Linux workstation or server:

COMPILING LINUX PACKAGES 
# Run the master compilation pipeline:
./scripts/build-linux-packages.sh

# Generated artifacts in dist-linux/:
1. zoth-linux-x86_64.run            (63MB Universal Self-Extracting Executable)
2. zoth-studio_2.6.0_all.deb        (40MB Native Debian/Ubuntu/Parrot Package)
3. zoth-studio-v2.6.0-linux.tar.gz  (46MB Portable Zero-Install Tarball)

Running the Single Executable (.run):

STANDALONE BINARY COMMANDS 
chmod +x zoth-linux-x86_64.run

# Run directly on loopback (opens :8484 and :8088):
./zoth-linux-x86_64.run

# Or install permanently into ~/.local/bin/zoth:
./zoth-linux-x86_64.run --install

# Or extract raw application files:
./zoth-linux-x86_64.run --extract

Automated Pre-Build Privacy Gate

During compilation, .buildignore is strictly enforced to purge all personal chat histories (conversations.json), BYOK secrets (byok.json), training datasets (*.jsonl), and development cache. An automated security audit verifies that zero personal files or cryptographic keys exist before packaging.

📡 7. Swarm Bus Protocol (`agent-comms/`)

Multi-agent coordination runs over structured file-based IPC in agent-comms/:

SWARM BUS CLI COMMANDS 
# Broadcast a message to all active swarm agents:
python3 agent-comms/bus.py post --from antigravity --to all --msg "Sprint deliverable verified"

# Acquire an exclusive lock on a project:
python3 agent-comms/bus.py claim --agent antigravity --project omnipost

# Release project lock upon completion:
python3 agent-comms/bus.py release --agent antigravity --project omnipost

# Inspect live swarm claims and agent heartbeats:
python3 agent-comms/bus.py who
python3 agent-comms/bus.py read --limit 10
