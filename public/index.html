🔒 AUDITABLE DATA BOUNDARIES

Designed to keep sensitive work on your device.

We believe in transparent technical descriptions over marketing hype. Here is exactly what stays local, what is optional, and how you can verify it.

💻 Always Local on Device
  • ✓ Workspaces & Code: All project files and outputs stay in your local filesystem.
  • ✓ API Key Vault: Stored strictly in local encrypted memory with Argon2id.
  • ✓ Loopback Orchestration: Agents communicate over local 127.0.0.1 services.
  • ✓ Transcripts & Histories: Stored locally on your machine, never monetized.
🔌 Optional External Routing
  • ✦ 100% Offline Mode: Use Ollama for zero-network local inference.
  • ✦ Bring Your Own Key (BYOK): Connect OpenAI, Anthropic, or Gemini directly.
  • ✦ Multi-Model Comparison: Cross-check answers across models to catch mistakes.
  • ✦ User-Controlled: Switch between offline-only and external LLMs at any time.
🔍 How You Can Verify
  • 🔍 DevTools Network Inspector: Inspect all HTTP/SSE streams in real time.
  • 🔍 Wireshark / Port Monitoring: Verify loopback traffic on :8484 and :8088.
  • 🔍 Open Source Codebase: Audit our Python, Rust, and JavaScript code on GitHub.
  • 🔍 Diagnostic Log Viewer: In-app trace inspector available in settings.
