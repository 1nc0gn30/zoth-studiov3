The 3-Agent Triangulation Protocol

Zoth Studio deploys a 3-agent arena over loopback IPC: Agent 1 (The Synthesizer) creates the AST, Agent 2 (The Adversarial Fuzzer) probes edge cases and type contradictions, and Agent 3 (The Arbitrator) verifies the deterministic diff.
