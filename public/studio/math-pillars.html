Linear Algebra

Tensors, Projections, Geometry & Attention

Scaled Dot-Product Attention Vaswani et al.
Attention(Q, K, V) = softmax( (Q · KT) / √dk ) · V

Computes affinity scores between Query and Key token projections scaled by dimension square root.

Rotary Position Embedding (RoPE) Su et al.
RΘ,md xm = [xm,1 cos(mθ) - xm,2 sin(mθ), ...]

Encodes relative token distance by rotating 2D query/key sub-vectors in the complex plane.

Low-Rank Adaptation (LoRA) Hu et al.
W = W0 + ΔW,   ΔW = (α / r) · (B · A)

Decomposes weight updates into low-rank matrices A ∈ ℝr×d_in and B ∈ ℝd_out×r where r ≪ d.

Multivariable Calculus

Gradients, Loss Surfaces & Parameter Updates

Cross-Entropy Loss & Perplexity Objective Function
ℒCE = -∑ yi log(p̂i),   PPL = exp(ℒCE)

Measures negative log-likelihood of target token sequences; exponent yields model branching factor.

AdamW Adaptive Parameter Update Loshchilov & Hutter
θt+1 = θt - η · ( m̂t / (√v̂t + ε) + λ θt )

Decoupled weight decay update using first and second gradient moments (m_t and v_t).

RMSNorm Layer Scaling Zhang & Sennrich
y = (x / RMS(x)) ⊙ γ,   RMS(x) = √( (1/d) ∑ xi2 + ε )

Scales activations by root mean square without shifting by mean, reducing training latency.
