# HexStrike AI Terminal
A sovereign security auditing tool that combines raw penetration testing utilities with LLM-powered intelligence.

## Capabilities
- **OSINT**: Email harvesting, subdomain enumeration, photon regex scraping.
- **Web Recon**: Nikto scanning, WhatWeb fingerprinting, Gobuster directory brute-forcing.
- **Infrastructure**: SQLmap banner grabbing, SNMP walking, Searchsploit matching, Nmap service auditing.
- **Intelligence**: Automated analysis of tool output via LocalAI.

## Operational Mode
This is a **Security-Tier** tool. It is only activated when the system is installed with the `--security` flag.

## Interface
Accessible via the Operator Deck at `/studio/hexstrike.html`.
