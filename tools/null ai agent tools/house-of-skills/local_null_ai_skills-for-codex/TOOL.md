# skills-for-codex

## Purpose
Agent skill library for Codex — provides modular skill packs (backend, frontend, supabase, netlify-seo) that extend Codex's capabilities through reusable prompt templates and configuration.

## Classification
- **Type**: Data-only / skill library
- **Not a runtime tool**: Contains no executable code or entrypoints
- **Contains**: Prompt templates, configuration files, and skill definitions

## Contents
- `backend/` — Backend skill definitions and templates
- `frontend/` — Frontend skill definitions
- `supabase/` — Supabase integration skills
- `netlify-seo/` — Netlify/SEO skill templates
- `main/` — Core skill orchestration
- `prompt-template.txt` — Example prompt template

## Usage
These skills are consumed by Codex during agent sessions. They are not executed directly.
