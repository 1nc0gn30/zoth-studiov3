# Marketplace Site Map

## Pages

- `/`: Product explanation and primary registry URL.
- `/catalog/`: Searchable pack list.
- `/packs/<id>/`: Human-readable pack detail page.
- `/docs/fetching/`: Runtime fetch flow and CLI examples.
- `/docs/manifest/`: Manifest contract.
- `/trust/`: Security model, publisher rules, checksums, reporting.
- `/changelog/`: Release notes and deprecations.

## Static Endpoints

- `/registry.json`
- `/packs/<id>/<version>/manifest.json`
- `/packs/<id>/latest/manifest.json`
- `/packs/<id>/<version>/checksums.txt`
- `/robots.txt`
- `/sitemap.xml`
