# Canon

Zoth is an original adult anime mascot: slick black hair, navy pinstripe three-piece, leather gloves, porcelain-and-obsidian full mask with a gold Z-slash and violet eye slits. No facial identity yet. Tarot-card stillness, Great Pretender con-artist mood, not a copy of Laurent Thierry.

Assets live in `/assets/mascot/` and the production mark is `/assets/brand/zoth-seal-mask.svg`.
